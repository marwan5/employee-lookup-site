# نظام الاستعلام عن بيانات الموظفين — Google Sheets

هذه النسخة تقرأ البيانات مباشرة من ورقة Google Sheets واحدة، ولا تحتاج إلى ملف Excel على الخادم.

## إعداد Google Sheets

1. افتح جدول الموظفين.
2. تأكد أن الصف الأول يحتوي على رؤوس الأعمدة التالية، بالأسماء نفسها:
   - `الرقم الوطني`
   - `الاسم الكامل`
   - `القطاع`
   - `الإدارة التابع لها`
   - `نوع الوظيفة`
   - `حالة الموظف`
   - `الفروقات`
3. تأكد أن الورقة المطلوبة هي الورقة الأولى (أو غيّر متغير `SHEET_GID` إلى رقم `gid` الصحيح من رابط الورقة).
4. طريقة الاتصال الافتراضية تستخدم رابط CSV للجدول، لذلك يجب أن يتمكن الخادم من قراءة الورقة. أسهل إعداد هو: **مشاركة → الوصول العام → أي شخص لديه الرابط → مشاهد**.

**تنبيه خصوصية:** هذا الإعداد يجعل بيانات الورقة قابلة للوصول لمن لديه الرابط، وقد يتيح تنزيلها كاملة. لا تستخدمه إذا كان الجدول يحتوي على بيانات لا يجوز نشرها. الخيار الأكثر أماناً هو استخدام Google Sheets API بحساب خدمة وصلاحيات محدودة.

## ما الذي يظهر للباحث؟

يُستخدم الرقم الوطني للبحث فقط ولا يظهر في النتيجة. الحقول المعروضة هي:
- الاسم الكامل
- القطاع
- الإدارة التابع لها
- نوع الوظيفة
- حالة الموظف
- الفروقات

## التشغيل محلياً

يتطلب Python 3.10 أو أحدث واتصالاً بالإنترنت.

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\\Scripts\\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

ثم:
```bash
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000` في المتصفح.

## إعدادات اختيارية

- `GOOGLE_SHEET_ID`: معرّف ملف Google Sheets.
- `SHEET_GID`: معرّف الورقة (الافتراضي `0`، أي الورقة الأولى عادةً).
- `SHEET_CSV_URL`: رابط CSV كامل إذا أردت تحديد رابط مخصص.
- `PORT`: منفذ التشغيل.

## النشر على الإنترنت

ارفع ملفات التطبيق إلى استضافة تدعم Python، ثم شغّله بخادم إنتاج مثل:
```bash
gunicorn app:app
```

استخدم HTTPS، ولا تضع بيانات اعتماد Google داخل الكود أو المستودع. تحديد معدل البحث في التطبيق مفيد لكنه لا يغني عن مراجعة أمنية قبل النشر. هذه الحزمة لا تنشر الموقع تلقائياً؛ يلزم اختيار استضافة وإتمام خطوات النشر.
